1) The popup “(sugg || []).map is not a function”

That’s a simple front‑end bug. The /api/suggest_by_file endpoint returns an object with a suggested array, not an array itself. So this line:

const suggestedCodes = (sugg || []).map(s => s.deliverable_code);


must be:

const suggestedCodes = (sugg?.suggested || []).map(s => s.deliverable_code);


(That endpoint returns { suggested: [...], filename } — not a bare array. Fixing the accessor prevents the .map error and gives you the codes needed to seed Stage 2 left‑panel and Step 3. )

While you’re here, make sure the Analyze flow uses the same selection everywhere:
