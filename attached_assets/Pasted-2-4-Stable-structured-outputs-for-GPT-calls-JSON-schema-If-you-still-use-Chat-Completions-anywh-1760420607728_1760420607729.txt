2.4 Stable structured outputs for GPT calls (JSON schema)

If you still use “Chat Completions” anywhere, switch to Responses API with json_schema (you already have gpt5_helpers.py). Keep max tokens conservative (e.g., 800–1200) and stream for responsiveness.

FILE: gpt5_helpers.py — add or update helper
def gpt_json(schema: dict, messages: list[dict], max_tokens: int = 1000) -> dict:
    from openai import OpenAI
    import json
    client = OpenAI()  # picks up env
    r = client.responses.create(
        model="gpt-5-pro",
        response_format={"type": "json_schema", "json_schema": {"name": "plan", "schema": schema}},
        input=messages,
        max_output_tokens=max_tokens,
        temperature=0.2,
    )
    return json.loads(r.output_text or "{}")

Why: Structured outputs (json_schema) improve determinism; Responses API + streaming reduces perceived latency.

3) Frontend wiring (non‑destructive)

FILE: static/app.js — add a thin client around Analyze
async function startAnalysis(requestText, strictness = "balanced", tier = "thinking") {
  const r = await fetch("/api/ai/analyze", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ request_text: requestText || "", strictness, tier })
  });
  const { job_id } = await r.json();
  return job_id;
}

async function pollStatus(job_id, onUpdate) {
  let done = false;
  while (!done) {
    const r = await fetch(`/api/ai/status/${job_id}`);
    const s = await r.json();
    if (onUpdate) onUpdate(s);
    if (s.status === "COMPLETED" || s.status === "FAILED") done = true;
    await new Promise(res => setTimeout(res, 700));
  }
  return done;
}

Hook this to your “Analyze with AI” button. For “Fast” mode, call /api/step2/ai/weights directly (skip LLM), update the selections, and allow “Deep” as an optional refinement.
