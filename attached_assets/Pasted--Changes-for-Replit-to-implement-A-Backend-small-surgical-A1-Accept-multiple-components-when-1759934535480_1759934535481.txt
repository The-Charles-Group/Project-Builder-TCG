C) Step 4 timeline (day math sanity)

Your XML export already writes a Mon–Fri working calendar (DayType 1=Sun & 7=Sat are non‑working; 2–6 are working). That’s correct.

What’s off is the UI display math for duration and end date (you caught a Saturday end). Use business‑day math in the front‑end timeline:

function addBusinessDays(start, days){
  const d = new Date(start);
  let added = 0;
  while (added < days) {
    d.setDate(d.getDate()+1);
    const dow = d.getDay();  // 0 Sun … 6 Sat
    if (dow !== 0 && dow !== 6) added++;
  }
  return d;
}


Use this to compute Step 4 End and Duration (days) so it matches the export calendar.

Do not count weekends; (holiday support can be added later by injecting an isHoliday(date) guard).
