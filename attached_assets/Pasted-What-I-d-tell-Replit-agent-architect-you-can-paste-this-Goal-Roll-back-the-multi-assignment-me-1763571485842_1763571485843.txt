Let hours = Planned_Hours for that row (or uid_to_sched[uid]['PlannedHours'] – whichever is canonical).

Use an 8-hour workday.

Compute:

required_days = max(1, ceil(hours / 8.0))

dur_minutes = required_days * 480 (480 minutes = 8 hours)

Export:

<Work> = hours * 60 minutes (as now)

<Duration> = PT{dur_minutes}M

Also update <Finish> to match the new duration:

Finish = Start + required_days * 1 workday

(however you currently handle adding days; just make sure Finish reflects the new Duration)

This guarantees:

A task with 3h → Duration = 1 day

8h → 1 day

11h → 2 days

22h (if ever on a single task) → 3 days, etc.

Importantly: you can no longer get 11 hours of work in a 0.12-day duration, which is exactly Ross’s complaint.
