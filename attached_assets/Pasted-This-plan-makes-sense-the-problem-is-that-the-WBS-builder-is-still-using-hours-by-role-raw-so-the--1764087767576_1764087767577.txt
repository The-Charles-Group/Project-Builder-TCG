1. Adjust role hours to match Step 3 Planned_Hours

For each deliverable item:

Let:

target_hours = get_hours_from_item(item) (Step 3 value)

role_hours = item["hours_by_role"] (dict of role → hours)

role_total = sum(role_hours.values())

If role_total > 0 and target_hours > 0:

scale = target_hours / role_total
scaled_hours_by_role = {role: hrs * scale for role, hrs in role_hours.items()}


Use scaled_hours_by_role when generating task/assignment rows so the sum of assignment Work for that deliverable’s WBS subtree = Step 3 Hours.

If role_total == 0, just use target_hours on a single row.
