2. Make the Save endpoint update scenario directly (no override maps)

Wherever the Step 3 grid “Save / autosave” hits (usually a PATCH like /api/pricing/scenario or /api/pricing/sync):

Load the working scenario from SCENARIO_STORE[session_id]["scenario"] using get_working_scenario.

For each edited row from the frontend, find the matching item inside scenario["items"] and update its fields in-place (hours, rate, price, cadence, etc.).

Recompute totals.

Call save_working_scenario(session_id, scenario).

Key thing: no more separate overrides dict. The canonical truth is the scenario["items"] list.

Add a canonical key helper so Save and any future rebuild logic use the same key:

def make_item_key(item: dict) -> str:
    dcode = str(
        item.get("deliverable_code")
        or item.get("Deliverable_Code")
        or ""
    ).strip().lower()

    comp = str(
        item.get("component")
        or item.get("Component")
        or item.get("component_name")
        or ""
    ).strip().lower()

    label = str(
        item.get("task_label")
        or item.get("Task_Label")
        or item.get("Task")
        or ""
    ).strip().lower()

    return f"{dcode}::{comp}::{label}"


Then in the Save endpoint, something like:

@app.patch("/api/pricing/scenario")
def api_patch_scenario(payload: dict):
    session_id = payload.get("session_id")
    edits = payload.get("items") or []

    if not session_id:
        raise HTTPException(400, "session_id required")

    scenario = get_working_scenario(session_id)
    items = scenario.get("items") or []

    # Build map for fast lookup
    item_map = {make_item_key(i): i for i in items}

    for edited in edits:
        key = make_item_key(edited)
        existing = item_map.get(key)
        if not existing:
            # optional: log and skip
            print(f"[STEP3 PATCH] No match for key {key}, skipping")
            continue

        # Update only the Step 3-editable fields
        for field in ["Planned_Hours", "planned_hours", "hours",
                      "Rate_USD", "rate_usd",
                      "Price_USD", "price_usd", "total_price",
                      "billing_cadence", "cadence_units",
                      "monthly_price", "cadence_price"]:
            if field in edited and edited[field] is not None:
                existing[field] = edited[field]

    # Recompute total_hours / total_price from the edited items
    scenario["totals"] = _recompute_scenario_totals(items)

    save_working_scenario(session_id, scenario)
    return {"ok": True, "scenario": scenario, "totals": scenario["totals"]}


The important part: when you click Save, the real scenario object is updated. There is no separate “override” to re-apply later.

3. Make Build Scenario use the working copy, not Step 2

Right now, the ScenarioManager.buildScenario() in the frontend is hitting /api/scenarios (the old Step 2 builder). That’s what’s nuking your edits.

You want this behavior:

Build Scenario (blue) → just re-hydrate the saved scenario from SCENARIO_STORE[session_id]["scenario"] and recompute totals. No rebuild from DB.

Reset from Step 2 (orange) → rebuild from Step 2 inputs, overwrite baseline + working copy.

Backend endpoint (example):

class BuildScenarioPayload(BaseModel):
    session_id: str
    reset: bool = False  # only True when clicking "Reset from Step 2"

@app.post("/api/pricing/build_scenario")
def api_pricing_build_scenario(payload: BuildScenarioPayload):
    session_id = payload.session_id
    reset = payload.reset

    if not DB.loaded:
        DB.load()

    if reset or session_id not in SCENARIO_STORE:
        # Rebuild baseline from Step 2 selection (call your existing api_build / /api/scenarios logic)
        base = build_scenario_from_step2(session_id)  # wrap your existing builder here
        _totals = _recompute_scenario_totals(base.get("items") or [])
        SCENARIO_STORE[session_id] = {
            "baseline": base,
            "scenario": json.loads(json.dumps(base)),
            "totals": _totals,
            "metadata": base.get("metadata", {})
        }

    entry = SCENARIO_STORE[session_id]
    scenario = get_working_scenario(session_id)
    items = scenario.get("items") or []
    entry["totals"] = _recompute_scenario_totals(items)
    entry["scenario"] = scenario
    SCENARIO_STORE[session_id] = entry

    return {
        "ok": True,
        "scenario": scenario,
        "totals": entry["totals"],
        "metadata": entry.get("metadata", {})
    }
