Quick ways to stop the noise (no behavioral change)

Serve something at / and /favicon.ico so platform pings don’t 404:

from fastapi.responses import FileResponse, HTMLResponse, RedirectResponse

@app.get("/")
async def root():
    # If you have a static index:
    if os.path.exists("static/index.html"):
        return FileResponse("static/index.html")
    # Otherwise, point people to the app
    return HTMLResponse("<h3>Agency Project Builder</h3><p>See <code>/api/health</code>.</p>")

@app.get("/favicon.ico")
async def favicon():
    path = "static/favicon.ico"
    return FileResponse(path) if os.path.exists(path) else HTMLResponse("", status_code=204)


(Your app already mounts /static for assets; this just wires the root and favicon.)

Don’t treat “unknown job” as an error. Return 200 with a neutral payload so automatic polls don’t surface as 404s:

@app.get("/api/agencydb/status/{job_id}")
async def get_agencydb_job_status(job_id: str):
    # ...existing lookup...
    if job_id not in AI_JOB_STORE:
        # keep HTTP 200 to avoid noisy 404 logs
        return {"job_id": job_id, "status": "not_found", "progress": 0, "message": "Job not found"}
    # existing success path...


(Today the code raises 404 when a job isn’t found; that’s why you see 404 spam during status polling.)

If you want full clarity about who is calling you

Add a tiny logging middleware to print path and user‑agent for 404s only. You’ll see quickly whether it’s a platform probe, a service worker, or the app’s polling:

from starlette.requests import Request

@app.middleware("http")
async def log_404s(request: Request, call_next):
    response = await call_next(request)
    if response.status_code == 404:
        ua = request.headers.get("user-agent", "-")
        print(f"[404] {request.method} {request.url.path} UA={ua}")
    return response

Why this matches the code you’re running

Health is /api/health only; root is undefined. That’s exactly what you have now (hence 404s on /).

Status endpoint 404s for missing jobs by raising HTTPException(404) when the job ID isn’t in AI_JOB_STORE (e.g., after a restart, the in‑memory store is empty).

Static frontend is mounted at /static, not /, so “Live site / preview” pings to / will 404 unless you add the root handler above
