3. Remove / quarantine old /api/scenarios logic

Find all old /api/scenarios endpoints in main.py.

Either:

Make them simple thin wrappers that delegate to /api/pricing/build_scenario, or

Comment them out entirely if the frontend never calls them.

In particular, remove/replace any lines like:

4. Replace raw SCENARIO_STORE[...] = scenario writes globally

Do a project-wide search for SCENARIO_STORE[ and fix every write that stores a plain scenario dict instead of the dual-entry structure.

Rules:

If it’s saving/adjusting Step 3 edits (e.g. pricing optimizations, cadence/retainer logic):
➜ change to:

update_working_scenario(session_id, scenario_data)


If it’s meant to rebuild from Step 2 / “Reset from Step 2”:
➜ change to:

set_baseline_and_scenario(session_id, scenario_data)


Any endpoints like /api/scenario/save, timeline save handlers, etc. that currently do:

SCENARIO_STORE[session_id] = scen_or_payload


should be routed through one of those two helpers, unless they are part of the migration helper that already wraps into {baseline, scenario, totals, metadata}.

print(f"[DEBUG] SCENARIO_STORE[{session_id}] keys:", list(SCENARIO_STORE[session_id].keys()))
