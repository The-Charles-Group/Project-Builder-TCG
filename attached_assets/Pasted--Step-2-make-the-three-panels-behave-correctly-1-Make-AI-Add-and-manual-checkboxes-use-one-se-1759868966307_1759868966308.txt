🗓️ Step 4 — never end on weekends, and show business‑day durations

You’re still seeing a Saturday in the Step 4 table. The exporter already writes a Mon–Fri calendar (Sunday & Saturday are non‑working in the generated XML). See the calendar block: Sunday (1) and Saturday (7) are DayWorking=0, Monday–Friday are working with two shifts.

So the fix is entirely in the timeline UI calculation, not in the exporter.

Fix (frontend):

Add pure business‑day helpers (no extra library required):

const HOLIDAYS = new Set<string>(/* ISO dates e.g., '2025-11-27' from DB if available */);

const fmt = (d: Date) => d.toISOString().slice(0,10);
const isBusinessDay = (d: Date) => {
  const w = d.getDay();               // 0 Sun ... 6 Sat
  return w !== 0 && w !== 6 && !HOLIDAYS.has(fmt(d));
};
const addBusinessDays = (start: Date, n: number) => {
  const d = new Date(start);
  let left = n;
  while (left > 0) {
    d.setDate(d.getDate() + 1);
    if (isBusinessDay(d)) left--;
  }
  return d;
};


When you render Step 4:

start = userProjectStart (from Step 3).

end = addBusinessDays(start, durationDays) (use the planned duration from the DB; you can keep your waterfall sequencing, just replace simple date + days with addBusinessDays).

Recompute the “Duration (days)” column as business days (not calendar days).

FYI, the exporter emits a Mon–Fri calendar with 8‑hr days, so Workfront will honor business‑day math even if you forget to resave in the app. See the generated XML calendar section in the server where Sunday/Saturday are non‑working; you’re good on the export side.

🧾 Export — two small but important guards

Top‑level project name and row #1 = “Project Summary”
The exporter already writes the user’s Project Name to <Project><Name> and uses “Project Summary” for the root task name instead of duplicating the project title. Keep this behavior.

Prevent [nan] START/END in Workfront
Add a name sanitizer when building your per‑deliverable sentinel tasks:

def _safe(s):
    return "" if s is None or (isinstance(s, float) and math.isnan(s)) else str(s)

safe_code = _safe(deliverable_code) or slugify(deliverable_name)
start_name = f"[{safe_code}] START"
end_name   = f"[{safe_code}] END"


Call this in the export builder right before you emit Task names for sentinel rows.
