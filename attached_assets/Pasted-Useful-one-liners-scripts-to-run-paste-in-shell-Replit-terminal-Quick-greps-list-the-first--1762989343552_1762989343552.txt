Useful one-liners & scripts to run (paste in shell / Replit terminal)

Quick greps:

list the first 200 <UID> occurrences with context (so you can eyeball ranges and overlaps):

grep -n "<UID>" /path/to/export.xml | sed -n '1,200p'


Extract UID values grouped by parent tag (Task vs Resource):

# Task UIDs
grep -n -A2 "<Task" /path/to/export.xml | grep -oP '(?<=<UID>)[0-9]+(?=</UID>)' | sort -n | awk 'NR==1{min=$1} {max=$1} END{print "min="min", max="max}'
# Resource UIDs
grep -n -A2 "<Resource" /path/to/export.xml | grep -oP '(?<=<UID>)[0-9]+(?=</UID>)' | sort -n | awk 'NR==1{min=$1} {max=$1} END{print "min="min", max="max"}'


Find task-level ExtendedAttribute nodes that include forbidden fields:

# show ExtendedAttribute blocks under Task that contain UID, ElementType, or CfType
awk 'BEGIN{RS="</Task>"} /<ExtendedAttribute>/ && /<UID>|<ElementType>|<CfType>/{print $0 "\n---"}' /path/to/export.xml


Find tasks where Duration > 0 but Work == 0 and have an assignment:

# crude XPath-like search using awk (works for typical MSPDI layout)
awk 'BEGIN{RS="</Task>"; FS="\n"} /<Duration>.*PT[0-9]+M.*<\/Duration>/ && /<Work>.*PT0M.*<\/Work>/ && /<Assignments>/{print $0 "\n---"}' /path/to/export.xml


Validate against an MSPDI XSD (if you have the schema file):

xmllint --noout --schema /path/to/mspdi.xsd /path/to/export.xml


(Note: xmllint may not be installed in Replit; if missing, pip-install libxml2 or run locally.)

If you prefer a small Python check (paste into a Python session) to find forbidden ExtendedAttribute fields under <Task>:

import xml.etree.ElementTree as ET
tree = ET.parse('/path/to/export.xml')
root = tree.getroot()
bad = []
for task in root.findall('.//Task'):
    for ea in task.findall('.//ExtendedAttribute'):
        for tag in ('UID','ElementType','CfType'):
            if ea.find(tag) is not None:
                bad.append((task.find('UID').text if task.find('UID') is not None else 'no-task-uid', tag))
print("Found", len(bad), "bad extended-attribute tags:", bad[:50])
