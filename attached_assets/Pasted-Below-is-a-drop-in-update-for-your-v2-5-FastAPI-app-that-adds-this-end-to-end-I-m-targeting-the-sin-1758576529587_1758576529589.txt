What this change does

Suggest screen (second screen)

The suggest APIs now return a retainer_hint and retainer_months_suggested for each deliverable based on simple, transparent heuristics (“monthly”, “always‑on”, “retainer”, “12 months”, etc.).

Your UI can render a Retainer checkbox and a Months number field (1–12) right next to each service row and prefill from the hint.

Build / Auto‑build

Both payloads accept a retainers array: [{ deliverable_code, months }].

Scenario items include retainer metadata (months, monthly_hours, monthly_price) and totals multiply accordingly.

WBS & Export

Retainer deliverables are expanded into repeating monthly task headers (e.g., “Month 01 – Community Management”), while Component remains your DB component (so you don’t lose component granularity).

Pricing remains hours × rate. Totals and durations roll up for all months.

Excel/CSV exports reflect the monthly repetition naturally in the hierarchy:
Project → Deliverable → Component → Task (Month nn – label) → Role rows.

Audit

/api/audit_pricing recognizes retainers and scales expected price by months.

2) Retainer heuristics for the suggest step

Add to AgencyDB (e.g., after suggest_deliverables_from_text)

    def retainer_recommendation(self, text: str, deliverable_name: str) -> tuple[bool, int]:
        """
        Very simple rule-of-thumb to suggest retainer and months.
        Returns (is_retainer, months) where months in [1..12].
        """
        t = (text or "").lower()

        # If RFP states an explicit month count, respect that (clamped to 1..12)
        import re
        m = re.search(r'\b(\d{1,2})\s*(?:months|mos|mo)\b', t)
        months = 0
        if m:
            try:
                months = max(1, min(12, int(m.group(1))))
            except Exception:
                months = 0

        # Soft indicators that the work is monthly/ongoing
        signals = [
            "retainer", "monthly", "per month", "each month", "every month",
            "always-on", "always on", "ongoing", "maintenance", "management",
            "reporting cadence", "monthly report", "social calendar", "community"
        ]

        is_signal = any(s in t for s in signals)

        # Some deliverables are very often retainers
        likely_retainer_keywords = [
            "social", "community", "media", "measurement", "reporting",
            "seo", "maintenance", "support", "content", "blog"
        ]
        is_likely_by_name = any(k in (deliverable_name or "").lower() for k in likely_retainer_keywords)

        is_ret = bool(is_signal or is_likely_by_name)
        if is_ret and months == 0:
            # Default sensible guess
            months = 12 if "year" in t or "annual" in t else 6

        return (is_ret, max(1, min(12, months)) if months else (12 if is_ret else 0))
