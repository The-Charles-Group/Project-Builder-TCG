🧩 Multi-Assignment + Unified Task Instruction Set

Objective:
Enable multiple resources, hours, and revenue to appear under one unified task — while keeping the correct start, end, and duration dates.

1️⃣ Core Behavior Change

Each shared event (same WBS prefix, Name, Start, Finish) should export as a single task that has multiple <Assignment>s — instead of separate tasks for each assignee.

Rules:

✅ If tasks share:

Same deliverable/component scope (WBS prefix up to level 4)

Same Name

Same Start + Finish timestamps
→ merge them into one.

✅ If they differ in any of the above → keep them separate (1:1).

2️⃣ How It Should Export in XML

Single Combined Task Example:

<Task>
  <UID>200</UID>
  <WBS>1.1.1.1.1</WBS>
  <Name>Client Review &amp; Revisions</Name>
  <Start>2026-01-05T08:00:00</Start>
  <Finish>2026-01-05T09:00:00</Finish>
  <Duration>PT60M</Duration>
  <Work>PT240M</Work> <!-- total 4h -->
  <DurationFormat>7</DurationFormat>

</Task>

3️⃣ Implementation Details

Call the merger before export:

merged_rows, uid_alias_map = group_multi_assignments(rows, uid_to_sched)
rows = merged_rows


⬆ This ensures all loops (<Tasks>, <Assignments>, <PredecessorLink>) use the merged rows.

In the <Tasks> loop:

Skip creating duplicate tasks for each assignee.

Only emit one <Task> when multi_assignment=True.

Set:

Work = sum(assign["work_hours"]) * 60
Duration = actual (Finish - Start)


DurationFormat = 7 (elapsed days)

CalendarUID = 1

In the <Assignments> loop:

For multi_assignment=True, iterate through:

for assign in row["assignments"]:
    <Assignment>
       <TaskUID>same task UID</TaskUID>
       <ResourceUID>role-based UID</ResourceUID>
       <Work>assign["work_hours"] * 60</Work>
       <Cost>assign["price_usd"]</Cost>
    </Assignment>


Units = Work / Duration (fractional units allowed)

In dependency remapping:

Remap all old assignee UIDs (from consumed rows) to the merged task UID using uid_alias_map.

4️⃣ Architect Validation Points

Before committing, architect must confirm:

✅ Each merged group has:

One <Task>

Multiple <Assignment>s

Duration/Work rolled up correctly

No duplicate ConstraintType / Start / Finish tags

✅ Start and Finish times are not shifted.
✅ Cost totals match sum of individual contributors.
✅ Dependency and outline levels remain valid.
