2) Compute dates on business days only (no Sat/Sun)

Problems

The grid shows Saturday end dates.

The XML calendar currently marks Saturday as working (DayType 6 → DayWorking 1). That must be non‑working.

Fixes

Grid calculation: Replace any naive start + durationDays with a business day adder:

function addBusinessDays(start: Date, days: number, holidays: Set<string>) {
  let d = new Date(start);
  let remaining = days;
  while (remaining > 0) {
    d.setDate(d.getDate() + 1);
    const wd = d.getDay(); // 0=Sun,6=Sat
    const iso = d.toISOString().slice(0,10);
    if (wd !== 0 && wd !== 6 && !holidays.has(iso)) {
      remaining--;
    }
  }
  return d;
}


MSP XML calendar: when writing the <WeekDays> calendar block, set:

Mon–Fri (DayType 2–6): DayWorking=1 with 09:00–12:00 and 13:00–17:00 (480 minutes/day).

Sat (6) and Sun (7): DayWorking=0.

Your current exports include Saturday as working; see the <WeekDay><DayType>6</DayType><DayWorking>1</DayWorking> lines in the produced XML — flip those to 0.

Acceptance

In the Step‑4 grid, end dates never land on Saturday/Sunday.

In Workfront/MS Project, the imported calendar shows weekends as non‑working.
