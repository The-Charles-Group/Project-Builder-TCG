What to tell the Architect (design instructions)

Copy/paste this to your Replit architect:

Architect Task: Align app scheduling model with Workfront’s roll-up behavior

Workfront treats parent tasks as rollups of children. If leaf tasks compress, parents compress.

Therefore the app must either:

Compute schedule down to the leaf task level (best), OR

If the app does not want true task-level scheduling yet, it must still give leaf tasks the same Start/Finish spans as their parent buckets, so rollups preserve the intended project timeline.

Recommended scheduling approach (to remove “work-wait-work” and gaps)

Within each Component window (start→finish):

Split the component duration into 3 phase windows:

general

internal_review

client_review

Allocate days by weight (planned hours by phase) but enforce minimums (ex: at least 1 business day per phase).

Set:

phase Start/Finish = those windows

role-tasks under each phase inherit the phase window (or subdivide further, but must stay inside it)

Then export:

Duration = business-day span of each task’s Start/Finish (not work-hours)

This eliminates idle gaps because the windows tile across the component span, and Workfront rollups will match the app.
