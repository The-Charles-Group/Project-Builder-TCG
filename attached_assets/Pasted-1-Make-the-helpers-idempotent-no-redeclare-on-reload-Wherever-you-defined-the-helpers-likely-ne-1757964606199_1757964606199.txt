1) Make the helpers idempotent (no redeclare on reload)

Wherever you defined the helpers (likely near the top of your main client script), replace any of these patterns:

const setText = (id, t) => { /* ... */ };
const setHTML = (id, h) => { /* ... */ };


or

function setText(id, t) { /* ... */ }
function setHTML(id, h) { /* ... */ }


with guarded, global assignments:

// Safe to run multiple times; never redeclares
window.setText  = window.setText  || function (id, t) {
  const el = document.getElementById(id);
  if (el) el.textContent = t;
};
window.setHTML  = window.setHTML  || function (id, h) {
  const el = document.getElementById(id);
  if (el) el.innerHTML = h;
};

// If you added other small helpers, guard them too:
window.qs       = window.qs       || ((sel, root=document) => root.querySelector(sel));
window.qsa      = window.qsa      || ((sel, root=document) => [...root.querySelectorAll(sel)]);
window.fmtUSD   = window.fmtUSD   || (n => Intl.NumberFormat('en-US',{style:'currency',currency:'USD',maximumFractionDigits:0}).format(n));
window.parseFilenameFromContentDisposition =
  window.parseFilenameFromContentDisposition || function (hdr) {
    if (!hdr) return null;
    const m = /filename\*?=(?:UTF-8''|")?([^\";]+)/i.exec(hdr);
    try { return decodeURIComponent(m?.[1] || '').replace(/\s+/g,' ').trim(); } catch { return (m?.[1]||'').trim(); }
  };


Why this works: we’re not creating new identifiers; we’re only assigning to window.<name> if it hasn’t been set yet. That’s immune to hot‑reload or accidental double‑inclusion.

If your timeline patch added new helpers in a separate <script> block, use this guarded style there as well so both blocks can run harmlessly.

2) Make sure the script isn’t included twice

Open static/index.html and confirm you have only one include of your main script (e.g., /static/app.js). Because the server mounts the static folder at /static, a duplicated tag will re‑execute the same file and hit the duplicate‑declaration landmine.

Quick check in the browser console:

[...document.scripts].map(s => s.src).filter(Boolean)


If you see the same /static/... URL twice, remove the duplicate <script> tag.

3) Avoid re‑injecting the same helpers during “Analyze”

If your “Analyze” button replaces a container’s .innerHTML with a block that also contains a <script>…</script>, the browser will execute it again. Keep all helper declarations in your main bundle; UI updates should only set content (no <script> tags in injected HTML).

4) Hard‑reload after the fix

Do a full refresh that bypasses cache (Chrome: Cmd/Ctrl‑Shift‑R). If devtools cache is on, disable “Disable cache” in the Network tab and reload.

Bonus: use a tiny namespace (optional)

If you’d rather keep the global namespace cleaner, you can move everything under window.APP and reference it explicitly:

window.APP = window.APP || {};
APP.setText = APP.setText || function(id,t){ /* ... */ };
APP.setHTML = APP.setHTML || function(id,h){ /* ... */ };


Then call APP.setText('aiSummaryCount', '105/500 words'), etc.
