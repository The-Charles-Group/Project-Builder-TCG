1) “Why aren’t deliverables indented in Workfront—why do I have to indent manually?”

Root cause (SoundCloud 11:51 file): That XML lacks <WBS> and <OutlineNumber> on tasks and sets many tasks to OutlineLevel=1. Without WBS/OutlineNumber, Workfront won’t build the tree, so everything imports flat.

Proof the new converter fixes this: The “workfront.xml” you attached contains WBS and OutlineNumber at multiple levels (e.g., 1.7.21, 1.7.21.1, etc.), which Workfront recognizes and indents on import.

Action
Make sure all exports run through the same converter used by “workfront.xml”, i.e., convert_excel_to_mspdi() (already wired into v2.5’s /api/export flow). It emits WBS/OutlineNumber, resources, assignments, and predecessors.

If a second microservice is being used, confirm it also calls convert_excel_to_mspdi (your app.py does).

2) “Planned duration shows in hours, not days.”

What you’re seeing: Workfront’s Tasks grid shows the Duration column in hours. Even though we set <DurationFormat>7</DurationFormat> (“days”), Workfront stores the field in minutes and renders hours in that grid.

What to fix (and what not to fight)

Keep exporting Start and Finish correctly; that’s the source of truth for actual schedule length.

Expect the grid’s Duration to show hours (e.g., 15 days ≈ 120 hours). This is normal for Workfront imports.

If you must show days: use a Workfront view that includes Planned Duration (days) or add a custom calculated column (Duration/8) in your Workfront view. The XML itself cannot force the UI to render that column in days.

# add to API (simple example) — return any selected codes that are retainer-eligible
@app.post("/api/retainer_detect")
def api_retainer_detect(payload: dict):
    selected_codes = [str(x) for x in (payload.get("deliverable_codes") or [])]
    # naive rule: categories/types we consider monthly
    retainerish = set(["Reporting","Development","Post-Production","Brand Style & Usage Guidelines"])
    out = []
    for code in selected_codes:
        row = DB.deliverables[DB.deliverables["Deliverable_Code"].astype(str)==code]
        if row.empty: 
            continue
        cat = str(row["Category"].iloc[0])
        if cat in retainerish:
            out.append({"deliverable_code": code, "suggested_months": 12})
    return {"retainers": out}
