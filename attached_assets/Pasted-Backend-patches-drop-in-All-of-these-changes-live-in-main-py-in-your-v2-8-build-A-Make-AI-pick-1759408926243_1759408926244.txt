Backend patches (drop‑in)

All of these changes live in main.py in your v2.8 build.

A) Make AI picks always carry components into scenarios & export

At the very top of your WBS/pricing builder, ensure we inflate components whenever the selection is missing or "__ALL__":

# inside build_wbs_with_pricing(...) or just before you derive per-deliverable rows
scenario = _inflate_components_if_missing(scenario)


This helper already exists and treats {"__ALL__": None} as “include everything”; it also normalizes empty lists to all components.

When building each item, always call _scenario_for_deliverable with selected_components from the UI for that deliverable. The function already supports both formats (list or dict) and will use default hours for None.

B) Apply retainer months to hours (no more “0 hours”)

Right after you compute task_hours for a component’s tasks (where you add rows for each leaf task), multiply by retainer_months if the deliverable is listed in the retainer map:

# pseudo-context inside the WBS row assembly
retainer_months = int((deliverable_retainer_map or {}).get(deliv_code, 0) or 0)
hours = float(task_hours)

if retainer_months > 0:
    hours *= retainer_months  # repeat monthly workload


Your retainer detector is already wiring months; we’re just applying it during row creation.

C) XML hierarchy and Workfront‑friendly flags

Your converter builds MSPDI from a WBS dataframe. Make sure the converter sets:

Summary=1 for any WBS_ID that is a parent of other rows, Summary=0 otherwise.

OutlineLevel = depth from root based on Parent_WBS_ID.

No assignments on summary rows (assign only at leaf tasks).

The export route already uses three key steps: inflate → build WBS → convert. This change belongs in the “convert” step where you walk the parent/child relationships from Parent_WBS_ID.

D) Duration consistency (hours vs days)

If you want “days” in Workfront, round durations to multiples of 480 minutes (8h day) when emitting MSPDI. The easiest way: when you compute task duration from hours, do:

minutes = int(round(hours * 60))
minutes = (minutes + 479) // 480 * 480  # snap to 1-day blocks


That stops Workfront from rendering 1.875d as “15h”.
