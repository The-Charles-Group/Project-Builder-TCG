(Passing codes prevents the server from silently deriving a different set — that’s the mismatch you’re seeing.)

When the user clicks “Apply Selection” (middle panel), compute the final codes:

function applySelection() {
  const curr = new Set(appState.selectedCodes);
  // add checked
  for (const s of recon.add)    if (isCheckedAdd(s.code))    curr.add(s.code);
  // delete checked
  for (const s of recon.delete) if (isCheckedDel(s.code))    curr.delete(s.code);
  appState.selectedCodes = [...curr];
  // Optionally, rebuild the left panel pricing with /api/build (Average)
}

Step 3 — make the Build button work

Wire the button to post the non‑empty appState.selectedCodes to /api/build:

async function buildScenariosAB() {
  if (!appState.selectedCodes || appState.selectedCodes.length === 0) {
    alert('No deliverables selected. Please complete Stage 2 first.');
    return;
  }

  const payload = {
    selected_deliverable_codes: appState.selectedCodes,          // <- required
    pricing_mode: getPricingModeFromUI(),                        // 'Flat_Blended' | 'Per_Resource'
    blended_rate: getBlendedRateFromUI(),                        // number or null
    rate_band: getRateBandFromUI(),                              // e.g., 'Standard_US'
    use_slack: getUseSlackFromUI(),
    slack_after_internal: getSlackInternalFromUI(),
    slack_after_client: getSlackClientFromUI(),
    slack_global_pct: getSlackPctFromUI(),
    project_start: getProjectStartFromUI() || null,
    scenario_a: getScenarioSpecAFromUI(),                        // {mode, complexity, tier...}
    scenario_b: getScenarioSpecBFromUI()
  };

  const resp = await fetch('/api/build', {
    method: 'POST',
    headers: {'Content-Type': 'application/json'},
    body: JSON.stringify(payload)
  });

  const scenarios = await resp.json();
  renderScenario('A', scenarios.A);
  renderScenario('B', scenarios.B);
}


/api/build returns { A: {...}, B: {...} } with items and totals; that’s what you render in the Step 3 cards.

Result: The Step‑3 “Build” call will succeed, which then enables Step 4 (timeline) and Step 5 (export).
