✅ Phase 2: Workfront Duration & Constraint Normalization Plan
Objective

Resolve duration compression (“0.12 days”), constraint inheritance, and summary task roll-up issues that appear after import — while preserving the validated structure from Phase 1.

1. Duration & Work Normalization
Rules

For leaf tasks (OutlineLevel ≥ 5)

<ConstraintType>0</ConstraintType> (ASAP)

Keep <Work> consistent with assigned hours (if none, default to PT60M).

<Duration> = (Finish - Start) rounded to nearest 60 min.

For summary tasks (OutlineLevel ≤ 4)

<Summary>1</Summary>

<Duration>PT480M</Duration> (1 day placeholder to avoid “0.12 days”).

<Work>PT0M</Work>

<DurationFormat>7</DurationFormat>

<Milestone>0</Milestone>

Validation

✅ No task in the final XML should display <Duration>PT0M</Duration> unless it’s a milestone.

2. Constraint Cleanup
Deliverables (OutlineLevel = 3)

<ConstraintType>2</ConstraintType> → Start No Earlier Than

<ConstraintDate> = their planned start (from app Gantt).

Finish Anchors (OutlineLevel = 4, suffix .99)

<ConstraintType>3</ConstraintType> → Must Finish On

<ConstraintDate> = deliverable end date.

<PredecessorLink> → FS dependency from last leaf UID only.

Leaf Tasks

Explicitly <ConstraintType>0</ConstraintType> → As Soon As Possible,
so they don’t inherit deliverable constraints.

3. Dependency Scope

Keep only dependencies within the same deliverable (L3).

Delete any <PredecessorLink> pointing between separate deliverables.

Summary and anchor tasks should never have incoming dependencies.

4. Structural Integrity Checks

Run these assertions after XML rebuild:

Check	Expected Result
count(PredecessorLink where OutlineLevel>=5)	0 ✅
Summary=1 → Work=PT0M	true for all ✅
Milestone=1 → Duration=PT0M	true ✅
Deliverables’ Start/Finish in XML match app Gantt	✅
Anchors exist for every deliverable (WBS suffix .99)	✅
5. Optional Enhancements

Add <CalendarUID> on all leaf tasks (optional, for fixed 8–5 alignment).

Include <Type>1</Type> and <IsEffortDriven>0</IsEffortDriven> for all leaves.

6. Test Plan

Export one deliverable XML after changes (e.g., Paid Media Strategy).

Import into Workfront Sandbox.

Validate:

“Start On” / “Due On” match Gantt.

Durations show real span (not 0.12 days).

Hours roll up correctly to deliverable summary.

If successful → run full export across all deliverables.

7. Naming for Consistency

Ensure all anchors use .99 suffix, not _FA.
E.g.,

1.1.2  → Brand Positioning Strategy
1.1.2.99 → Brand Positioning Strategy - Finish Anchor
