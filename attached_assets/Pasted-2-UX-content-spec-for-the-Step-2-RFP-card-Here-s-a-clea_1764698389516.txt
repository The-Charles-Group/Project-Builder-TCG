class RfpSummaryItem(BaseModel):

class RfpSummary(BaseModel):

3.2. Make ai_summarize_rfp_text return the full shape

Inside ai_summarize_rfp_text, we want one GPT call that returns:

{
  "channels": [...],
  "markets": [...],
  "complexity": "Low|Medium|High",
  "deliverables": [
    { "label": "...", "short_desc": "...", "deliverable_code": "" }
  ]
}


In English: update its JSON schema + parsing so that:

The system / user prompt tells GPT:

Extract 5–10 key deliverables with short 1–2 sentence descriptions.

Infer likely marketing channels as a short list (max ~8; canonical names like “Paid Social”, “Search”, “OOH”, “PR”, “Experiential”, etc.).

Infer markets (cities/regions/countries) from the RFP.

Estimate project complexity (Low, Medium, High) based on scope / channels / markets.

Return exactly the JSON schema above (no extra fields).

When parsing the GPT response, do something like:

channels = [c.strip() for c in data.get("channels") or [] if c.strip()]
markets = [m.strip() for m in data.get("markets") or [] if m.strip()]
complexity = (data.get("complexity") or "").strip().title() or None
deliverables_raw = data.get("deliverables") or []


Build a bullet‑friendly summary_text from the deliverables instead of just dumping raw RFP text. For example:

def _build_summary_text(deliverables: List[RfpSummaryItem]) -> str:
    if not deliverables:
        return "No clear deliverables were detected in the RFP. Please review the uploaded document."

    bullets = []
    for d in deliverables[:6]:
        label = d.label.strip()
        desc = (d.short_desc or "").strip()
        if desc:
            bullets.append(f"• {label}: {desc}")
        else:
            bullets.append(f"• {label}")
    return "\n".join(bullets)


Then in ai_summarize_rfp_text:

items = [RfpSummaryItem(**item) for item in deliverables_raw]
summary_text = _build_summary_text(items)
word_count = len((summary_text or "").split())

return RfpSummary(
    summary_text=summary_text,
    deliverables=items,
    word_count=word_count,
    channels=channels,
    markets=markets,
    complexity=complexity or "Medium"  # sensible default
)
