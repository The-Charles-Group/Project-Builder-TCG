🛠 Step‑by‑step fixes for Step 4 — Timeline (no weekends)

Where: the client-side timeline calculation util (whatever computes Start/End shown in the Step 4 table).
The exporter already produces a 5‑day calendar, but your UI dates are computed as calendar days—hence Saturday end dates.

Use this exact helper and replace your start + duration math with business days:

function isWeekend(d) {
  const day = d.getDay(); // 0 Sun, 6 Sat
  return day === 0 || day === 6;
}

function addBusinessDays(startDate, days, holidaysSet = new Set()) {
  let d = new Date(startDate);
  // If start lands on weekend, roll to Monday
  while (isWeekend(d) || holidaysSet.has(d.toISOString().slice(0,10))) {
    d.setDate(d.getDate()+1);
  }
  let remaining = Math.max(0, Number(days));
  while (remaining > 0) {
    d.setDate(d.getDate()+1);
    const iso = d.toISOString().slice(0,10);
    if (!isWeekend(d) && !holidaysSet.has(iso)) {
      remaining -= 1;
    }
  }
  // End must not be weekend/holiday; roll back to previous business day
  while (isWeekend(d) || holidaysSet.has(d.toISOString().slice(0,10))) {
    d.setDate(d.getDate()-1);
  }
  return d;
}


Build a US holiday set (optional pass‑through from server) and feed it as holidaysSet.

Use addBusinessDays(projectStart, durationDays) for each deliverable and display that End date.

Keep the same project_start you’re already storing on the scenario (server has it in the scenario object).
