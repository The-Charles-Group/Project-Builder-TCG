✅ XML Structure Template for Correct Imports

Below is the minimal, “golden” structure that Replit’s importer handled successfully.
This format ensures all predecessors, assignments, planned hours, and planned revenue compute correctly.

<?xml version="1.0" encoding="UTF-8"?>
<Project xmlns="http://schemas.microsoft.com/project">
  <Name>PROJECT_NAME</Name>
  <StartDate>2025-11-17T01:00:00</StartDate>
  <MinutesPerDay>480</MinutesPerDay>
  <DurationFormat>7</DurationFormat>

  <Calendars>
    <Calendar>
      <UID>1</UID>
      <Name>Standard</Name>
      <IsBaseCalendar>1</IsBaseCalendar>
      <WeekDays>
        <WeekDay>
          <DayType>2</DayType>
          <DayWorking>1</DayWorking>
          <WorkingTimes>
            <WorkingTime><FromTime>08:00:00</FromTime><ToTime>12:00:00</ToTime></WorkingTime>
            <WorkingTime><FromTime>13:00:00</FromTime><ToTime>17:00:00</ToTime></WorkingTime>
          </WorkingTimes>
        </WeekDay>
        <!-- Repeat for DayType 3–6 -->
      </WeekDays>
    </Calendar>
  </Calendars>

  <Resources>
    <Resource>
      <UID>1</UID>
      <Name>Account Manager</Name>
      <Type>1</Type>
      <StandardRate>195.00</StandardRate> <!-- numeric, no $ or /h -->
    </Resource>
    <Resource>
      <UID>23</UID>
      <Name>Unassigned</Name>
      <Type>1</Type>
      <StandardRate>195.00</StandardRate>
    </Resource>
  </Resources>

  <Tasks>
    <Task>
      <UID>1</UID>
      <Name>Kickoff</Name>
      <Start>2025-11-17T01:00:00</Start>
      <Finish>2025-11-17T09:00:00</Finish>
      <Duration>PT480M</Duration>
      <Work>PT480M</Work>
      <OutlineLevel>2</OutlineLevel>
    </Task>

    <Task>
      <UID>2</UID>
      <Name>Concept Development</Name>
      <Start>2025-11-17T09:00:00</Start>
      <Finish>2025-11-17T17:00:00</Finish>
      <Duration>PT480M</Duration>
      <Work>PT480M</Work>
      <OutlineLevel>2</OutlineLevel>
      <PredecessorLink>
        <PredecessorUID>1</PredecessorUID> <!-- ensures dependency -->
        <Type>1</Type> <!-- 1 = Finish-to-Start -->
      </PredecessorLink>
    </Task>
  </Tasks>

  <Assignments>
    <Assignment>
      <TaskUID>1</TaskUID>
      <ResourceUID>1</ResourceUID>
      <Work>PT480M</Work>
      <Cost>1560.00</Cost> <!-- optional; importer can compute -->
    </Assignment>
    <Assignment>
      <TaskUID>2</TaskUID>
      <ResourceUID>1</ResourceUID>
      <Work>PT480M</Work>
      <Cost>1560.00</Cost>
    </Assignment>
  </Assignments>
</Project>

⚙️ Required Field Rules
Section	Field	Expected Format	Notes
Resources	<StandardRate>	decimal (e.g., 195.00)	No currency symbols or “/h” — string formatting breaks parsers in 5:09 PM/5:15 PM exports

sa-server-file-api-user-upload


Tasks	<Work> & <Duration>	ISO 8601 durations (PTxxxM)	1 hour = PT60M
Tasks	<PredecessorLink>	must include <PredecessorUID> and <Type>1</Type>	Required for dependency chains
Assignments	<TaskUID> / <ResourceUID>	integers matching UIDs	Connect tasks and resources
Assignments	<Cost>	decimal (optional)	Replit can derive from Work × StandardRate
Calendar	Working times	08:00–12:00 / 13:00–17:00	As in the correct export

sa-server-file-api-user-upload

🚫 Avoid These (from broken files)
Problem	Example	File
Formatted rate strings	<StandardRate>$195.00/h</StandardRate>	

sa-server-file-api-user-upload


Missing <PredecessorLink> chains	—	Both 5:09 PM and 5:15 PM
“Revenue” stored in <ExtendedAttribute>	<Alias>Revenue</Alias>	

sa-server-file-api-user-upload


Time shifts to 09–18h	<FromTime>09:00:00</FromTime>	later exports
