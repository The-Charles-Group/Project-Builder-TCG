Add predecessor links between tasks (FS by default)
In each child task, include one or more <PredecessorLink> blocks so Workfront can chain them and eliminate idle time. Minimal example to place after the child task’s fields:

<PredecessorLink>
  <PredecessorUID>123</PredecessorUID>  <!-- prior task UID -->
  <Type>1</Type>                         <!-- 1 = Finish-to-Start -->
  <LinkLag>0</LinkLag>
  <LagFormat>7</LagFormat>               <!-- 7 = days/minutes format used in your file -->
</PredecessorLink>


Right now the file uses constraints like ConstraintType=2 + ConstraintDate (e.g., 2025‑11‑17); replace those with ConstraintType=0 (ASAP) on regular tasks so predecessors drive timing instead of pins that create gaps.
