B. Rebuild a clean L2 FS chain

Now add a second pass that builds the tight waterfall chain:

# 1. Get the deliverables in chronological / WBS order
deliverable_tasks = []
task_by_uid = {}

for task in project.findall("Tasks/Task"):
    uid = int(task.findtext("UID", "0") or 0)
    outline = int(task.findtext("OutlineLevel", "0") or 0)
    if outline == 2:
        deliverable_tasks.append(task)
    task_by_uid[uid] = task

# sort by WBS or Start date — whichever is currently used
deliverable_tasks.sort(
    key=lambda t: t.findtext("WBS") or t.findtext("Start")
)

# 2. Add exactly one FS predecessor per deliverable after the first
for prev_task, curr_task in zip(deliverable_tasks, deliverable_tasks[1:]):
    prev_uid = int(prev_task.findtext("UID", "0") or 0)

    pl = SubElement(curr_task, "PredecessorLink")
    SubElement(pl, "PredecessorUID").text = str(prev_uid)
    SubElement(pl, "Type").text = "1"          # 1 = Finish-to-Start
    SubElement(pl, "CrossProject").text = "0"
    SubElement(pl, "LinkLag").text = "0"
    SubElement(pl, "LagFormat").text = "7"     # Same as existing links


Rules:

First deliverable: no PredecessorLink.

Each later deliverable: exactly one PredecessorLink, pointing to the immediately previous deliverable in that sorted list.

Do not add additional links between deliverables (no second “extra” predecessor).

deliverable_graph = {uid: [] for uid in deliverable_uid_set}
