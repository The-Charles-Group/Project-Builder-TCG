Step B — Fix the schedule builder: stop using PlannedHours to drive Finish

This block is the mismatch factory: 

12.12.25 app gantt timeline sho…

Replace it with day-based scheduling (Mon–Fri), using Duration_Days as authoritative.

Implementation pattern:

Use business-day add for offsets (NOT timedelta(days=...))

Compute finish = start + (duration_days - 1 business days)

Set times consistently with an 8-hour workday (recommend 09:00–17:00)

Pseudo-code:

WORKDAY_START = datetime.time(9, 0)
WORKDAY_END   = datetime.time(17, 0)
MINUTES_PER_DAY = 480

def add_business_days(d: date, n: int) -> date:
    # n can be 0
    step = 1 if n >= 0 else -1
    cur = d
    remaining = abs(n)
    while remaining > 0:
        cur += datetime.timedelta(days=step)
        if cur.weekday() < 5:  # Mon-Fri
            remaining -= 1
    return cur

def schedule_row(project_start_date: date, start_offset_days: int, duration_days: int):
    duration_days = max(1, int(duration_days or 1))
    start_date = add_business_days(project_start_date, int(start_offset_days or 0))
    finish_date = add_business_days(start_date, duration_days - 1)
    return (
        datetime.datetime.combine(start_date, WORKDAY_START),
        datetime.datetime.combine(finish_date, WORKDAY_END),
        duration_days
    )


Critical: don’t compute finish from PlannedHours. Planned hours should populate <Work> only — not drive the timeline.
