3️⃣ Keep child tasks inside their parent deliverable

This is the second big source of messy dependencies in Workfront.

Right now, a lot of L3+/child tasks still have predecessors that point into other deliverables (e.g., a component under “Campaign Strategy” depending directly on a task under “Paid Media Strategy”). That’s what Ross was pointing at with the “work–wait–work–wait” gaps. When those cross‑L2 predecessors exist, Workfront uses them to schedule, even if your L2 chain says something else.

Instructions for Replit:

When building <PredecessorLink> elements for L3+ tasks:

Compute the parent L2 WBS prefix for both predecessor and successor (e.g. 1.3 for 1.3.4.2).

If parent_l2(predecessor) != parent_l2(successor), drop that predecessor in tight‑waterfall mode.

In pseudocode:

if TIGHT_WATERFALL and is_child_task(task):
    keep_links = []
    for link in original_predecessors:
        if parent_L2(link.predecessor) == parent_L2(task):
            keep_links.append(link)
    task.predecessors = keep_links


Allow internal structure to stay intact.

Dependencies within a deliverable (e.g., “Research → Draft → Internal Review”) should be preserved.

Only cross‑deliverable predecessors are stripped.

Milestones exception again.

Milestones can depend on tasks from multiple deliverables; that’s OK, since they sit at the very end and don’t break the L2 waterfall.

Just don’t let milestones become predecessors of L2 deliverables in the chain.

Result: when you view “Deliverables only” in Workfront, the dependency lines you see should be a neat stair‑step: each L2 finishing, next L2 starting, no random lines jumping halfway down the grid.

4️⃣ Calendar & weekends

Your XML currently defines a “Standard” calendar where Monday–Saturday are working days, Sunday non‑working, with 8‑hour days.

Workfront often uses a 5‑day workweek. When it re‑schedules:

Duration in days can change a bit (because “5 days” of work in a 6‑day calendar is not “5 days” in a 5‑day one).

That can slightly shift end dates and break perfect alignments, even if the dependencies are correct.

If you want Workfront to be the source of truth on weekends:
You can leave the calendar as‑is; Workfront will remap to its own schedule. The waterfall shape should still be OK once the dependency and constraint logic above is fixed.

If you want XML to match Workfront’s 5‑day week more closely:
Ask Replit to change the calendar in convert_excel_to_mspdi so DayType 6 (Saturday) has DayWorking=0, and keep MinutesPerDay/Week as 480/2400.
