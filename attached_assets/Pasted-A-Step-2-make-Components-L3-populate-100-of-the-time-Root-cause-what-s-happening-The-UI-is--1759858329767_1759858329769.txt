A) Step 2 — make Components & L3 populate 100% of the time
Root‑cause (what’s happening)

The UI is tracking selections in two places (AI panel vs. Deliverables column). When you click Add in the AI box, it updates one state bucket but the Components/L3 panels are reading from a different one — net effect: the “Select a deliverable first…” gate never opens.

When you uncheck a deliverable that came from AI, the AI list is never told to re‑show its Add button for that item.

The Step 2 page loses the RFP text after navigation/refresh, so Refresh AI Suggestions thinks there’s “No RFP text in memory,” even though you can’t reach Step 2 without having uploaded/pasted one. The backend only persists the last filename, not the RFP body, so the panel truly has nothing to re‑use if the front‑end doesn’t cache it.

Required UI changes (React/Vue/TS – adapt to your stack)

One source of truth for selection:

Create a single selection store for Step 2:

type SelectionState = {
  deliverables: Set<string>; // deliverableCode
  components: Set<string>;   // `${deliverableCode}::${componentCode}`
  l3: Set<string>;           // `${deliverableCode}::${componentCode}::${subtaskCode}`
}


Keep it in a top‑level Step 2 provider (or Zustand/Redux atom) so AI panel and three columns read/write the same object.

Wire the AI “Add” buttons to the same store:

function addFromAISuggestion(deliverableCode: string) {
  selection.deliverables.add(deliverableCode);
  // ensure components panel wakes up
  setActiveDeliverable(deliverableCode);
  loadComponentsFor(deliverableCode); // same loader the left column uses
  ui.flash('components');             // optional: focus panel
}

function removeDeliverable(deliverableCode: string) {
  // remove L2/L3 that belong to it
  for (const key of Array.from(selection.components)) {
    if (key.startsWith(deliverableCode + '::')) selection.components.delete(key);
  }
  for (const key of Array.from(selection.l3)) {
    if (key.startsWith(deliverableCode + '::')) selection.l3.delete(key);
  }
  selection.deliverables.delete(deliverableCode);
  // tell AI list it can re‑show the Add button
  aiState.markAsUnselected(deliverableCode);
}


Populate Components & L3 immediately:

On selection.deliverables change, call:

useEffect(() => {
  if (!activeDeliverable && selection.deliverables.size) {
    setActiveDeliverable([...selection.deliverables][0]);
  }
  if (activeDeliverable) loadComponentsFor(activeDeliverable); // fetch once, cache

When any component checkbox flips on, load its L3:

function onToggleComponent(deliverableCode: string, componentCode: string, checked: boolean) {
  const key = `${deliverableCode}::${componentCode}`;
  if (checked) {
    selection.components.add(key);
    if (!l3Cache[key]) loadL3For(deliverableCode, componentCode);
  } else {
    selection.components.delete(key);
    // remove its L3 children too
    for (const k of Array.from(selection.l3)) if (k.startsWith(key + '::')) selection.l3.delete(k);
  }
}

When you tick/untick, move items between the two groups in memory rather than re‑querying.

Clear Deliverables ⇒ also clear Components & L3

B) Make “Refresh AI Suggestions” reliable
The bug

After navigation/refresh, the AI card says “No RFP text in memory”. That’s because the server only remembers the last upload filename, not the RFP text itself; the Step 2 panel must supply the text again.

Fix (front‑end only; minimal change)

When Step 1 finishes, persist the cleaned RFP text in localStorage:

localStorage.setItem('apb.rfpText.v1', rfpPlainText);


In Step 2, on mount:

const persisted = localStorage.getItem('apb.rfpText.v1');
if (persisted) aiState.setRfpText(persisted);


Make the Refresh AI Suggestions button call your AI endpoint with this rfpText payload when present; do not block the click with the “No RFP” alert if localStorage has it.

(Optional server assist): If you prefer a server cache, add /api/session/rfp with in‑memory store keyed by a client GUID; but the above localStorage approach is simpler and stateless.

1) Step 2 state (one source of truth)
// selectionStore.ts
import { create } from 'zustand';

type SelectionState = {
  deliverables: Set<string>;
  components: Set<string>;
  l3: Set<string>;
  clearAll: () => void;
  addDeliverable: (code: string) => void;
  removeDeliverable: (code: string) => void;
  toggleComponent: (d: string, c: string, on: boolean) => void;
  toggleL3: (d: string, c: string, t: string, on: boolean) => void;
};

export const useSelection = create<SelectionState>((set, get) => ({
  deliverables: new Set(),
  components: new Set(),
  l3: new Set(),
  clearAll: () => set({ deliverables: new Set(), components: new Set(), l3: new Set() }),
  addDeliverable: (d) => set(s => ({ ...s, deliverables: new Set(s.deliverables).add(d) })),
  removeDeliverable: (d) => set(s => {
    const deliv = new Set(s.deliverables); deliv.delete(d);
    const comps = new Set([...s.components].filter(k => !k.startsWith(d + '::')));
    const l3    = new Set([...s.l3].filter(k => !k.startsWith(d + '::')));
    return { ...s, deliverables: deliv, components: comps, l3 };
  }),
  toggleComponent: (d, c, on) => set(s => {
    const key = `${d}::${c}`;
    const comps = new Set(s.components);
    if (on) comps.add(key); else {
      comps.delete(key);
      // drop their subtasks
      const l3 = new Set([...s.l3].filter(k => !k.startsWith(key + '::')));
      return { ...s, components: comps, l3 };
    }
    return { ...s, components: comps };
  }),
  toggleL3: (d, c, t, on) => set(s => {
    const key = `${d}::${c}::${t}`;
    const l3 = new Set(s.l3);
    on ? l3.add(key) : l3.delete(key);
    return { ...s, l3 };
  })
}));

// AISuggestionsPanel.tsx
import { useSelection } from './selectionStore';

function AISuggestionRow({ deliverable }) {
  const addDeliverable = useSelection(s => s.addDeliverable);
  const isSelected = useSelection(s => s.deliverables.has(deliverable.code));
  return (
    <div className="ai-row">
      <span>{deliverable.name}</span>
      {!isSelected ? (
        <button onClick={() => addDeliverable(deliverable.code)}>Add</button>
      ) : (
        <span className="tag">selected</span>
      )}
    </div>
  );
}
