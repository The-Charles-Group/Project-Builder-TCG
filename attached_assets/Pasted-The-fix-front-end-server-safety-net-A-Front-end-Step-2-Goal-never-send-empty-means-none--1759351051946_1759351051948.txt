The fix (front‑end + server safety net)
A) Front‑end (Step‑2)

Goal: never send “empty means none.” If the user didn’t touch a deliverable’s Components modal, treat it as ALL components.

When adding deliverables (manually or from AI):
If componentSelections[code] is unset, set it to a sentinel (e.g., "__ALL__") rather than [].

When building the payload for /api/build:

// before fetch('/api/build'...)
const compMap = {};
for (const code of selectedCodes) {
  const sel = componentSelections[code];
  // Only include the key if the user actually narrowed components
  if (Array.isArray(sel) && sel.length > 0) {
    compMap[code] = sel;                // list format supported by API
  } else if (sel && typeof sel === 'object') {
    // hours-per-component variant is also supported by API – keep as-is
    compMap[code] = sel;
  } // else: omit key entirely => means "ALL" components
}

const payload = {
  selected_deliverable_codes: selectedCodes,
  selected_components_map: Object.keys(compMap).length ? compMap : undefined,
  // ...rest of your fields (scenarios, rates, slack, start date, etc.)
};


Why: the Build API model treats selected_components_map as optional (list or dict), so omitting a code tells the server to include all components.

UI polish: when AI drops items into “Your Selection,” resolve the label from /api/options so you show “Development” instead of “DEL‑0029”. (You already have the options list in memory; just map code → label when rendering that chip.)

B) Server (defensive normalization)

Add a tiny normalization so even if the client ever sends an empty selection, it’s interpreted as ALL (never “NONE”).

Somewhere near your /api/build handler, right after you parse the BuildPayload:

def _normalize_comp_map(comp_map):
    """Treat empty lists/dicts as 'ALL components' by removing the key."""
    if not comp_map:
        return {}
    out = {}
    for code, val in comp_map.items():
        if val is None:
            continue  # means ALL
        if isinstance(val, list) and len(val) == 0:
            continue  # treat empty list as ALL
        if isinstance(val, dict) and not any(float(v or 0) > 0 for v in val.values()):
            continue  # no positive hours -> ALL
        out[code] = val
    return out
