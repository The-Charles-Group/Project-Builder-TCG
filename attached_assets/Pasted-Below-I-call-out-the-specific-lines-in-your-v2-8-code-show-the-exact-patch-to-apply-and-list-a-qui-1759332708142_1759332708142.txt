Minimal, safe patch for the exporter (drop‑in)

Where: your MSPDI writer where you currently build <Project> / <Tasks> (the block that contains the code in the citations above).

A) Canonicalize WBS and write proper outline fields
def _canon_wbs(s: str) -> str:
    """
    Normalize '1.0' → '1', '1.0.1' → '1.1', remove empty/zero segments.
    Ensures MSPDI-friendly outline numbers like '1', '1.1', '1.1.1'.
    """
    parts = [p for p in str(s).split('.') if p not in ('', '0')]
    return '.'.join(parts) if parts else '1'


Then inside your task loop before writing WBS:

wbs_raw = str(r["WBS"])
wbs = _canon_wbs(wbs_raw)
SubElement(task, "WBS").text = wbs
SubElement(task, "OutlineNumber").text = wbs
SubElement(task, "OutlineLevel").text = str(wbs.count('.') + 1)  # 1-based


(You currently write WBS and OutlineNumber from r["WBS"] and never write a correct OutlineLevel. )
