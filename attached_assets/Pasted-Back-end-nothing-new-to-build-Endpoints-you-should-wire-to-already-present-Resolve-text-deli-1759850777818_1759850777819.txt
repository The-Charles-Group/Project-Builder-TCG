2) Wire the AI Suggestions rows

Each row should have an idempotent button that toggles “Add/Remove” without disappearing:

async function toggleSuggestedDeliverable(rowEl, code, add) {
  if (add) {
    APB.step2.selectedCodes.add(code);
    rowEl.querySelector('.btn-suggest').textContent = 'Remove';
    rowEl.querySelector('.btn-suggest').dataset.mode = 'remove';
  } else {
    APB.step2.selectedCodes.delete(code);
    rowEl.querySelector('.btn-suggest').textContent = 'Add';
    rowEl.querySelector('.btn-suggest').dataset.mode = 'add';
  }
  renderDeliverablesPanel();        // refresh left panel (selected go on top)
  await refreshComponentsPanel();   // re-fetch components for the current selection
  updateSummaryCounts();
}


Never delete the suggestion row; only flip the button mode.

4) Components panel wiring

Dropdown “Select a deliverable first…” should target the currently active deliverable (e.g., the most recently clicked selected code or the first from selectedCodes).

On change (deliverable), call /api/components_for with the complexity & tier that Pricing will use.

async function refreshComponentsPanel() {
  const code = getActiveDeliverableCode();
  const { complexity, tier } = APB.step2;
  const res = await fetch(`/api/components_for?deliverable_code=${encodeURIComponent(code)}&complexity=${encodeURIComponent(complexity)}&tier=${encodeURIComponent(tier)}`);
  const json = await res.json(); // { items: [{name, hours}] }
  renderComponentsChecklist(code, json.items);
}


“Select All / Clear” update selectedComponentsByCode and Summary counts.

5) L3 panel wiring

The L3 dropdown depends on both the active deliverable and the selected component.

Call /api/l3_for?deliverable_code=CODE&component_name=COMP and render a checkbox list.

async function onComponentClicked(componentName) {
  const code = getActiveDeliverableCode();
  const res = await fetch(`/api/l3_for?deliverable_code=${encodeURIComponent(code)}&component_name=${encodeURIComponent(componentName)}`);
  const { items } = await res.json(); // [{Task_Label}]
  renderL3Checklist(code, componentName, items.map(i => i.Task_Label));
}
